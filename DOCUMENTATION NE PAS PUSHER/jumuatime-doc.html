Guide d'autonomie — jumuatime.com

Référence complète pour gérer et modifier ton site sans Claude

Comment utiliser ce guide
Tout le code source est dans D:\DEV\jumuatime\ sur ton ordinateur. Les fichiers s'ouvrent dans VS Code. Pour mettre en ligne : ouvre un terminal dans VS Code (Ctrl+ù), tape git add -A && git commit -m "description" && git push — Cloudflare Pages déploie automatiquement en 1–2 minutes.

Architecture du site

🖥️ Front-end

Pages HTML statiques + JavaScript vanilla. Tailwind CSS CDN pour les classes utilitaires. Hébergé sur Cloudflare Pages.

🗄️ Base de données

Supabase (PostgreSQL). Stocke produits, commandes, utilisatrices, abonnées. Accessible depuis supabase.com/dashboard → projet Jumuatime.

💳 Paiements

Stripe LIVE — vrais paiements. Ne jamais toucher au mode test. Dashboard sur dashboard.stripe.com.

📦 Impression

Gelato — impression et envoi automatique des produits physiques Gelato (cartes, affiches). Les mugs bundle sont envoyés manuellement.

📧 Emails

Resend — emails transactionnels (confirmation commande, expédition). From : contact@jumuatime.com.

Flux d'une commande physique : Cliente paie → Stripe → webhook Cloudflare → Gelato (si Gelato) ou toi (si manuel) → tu changes le statut en "expedie" dans l'admin → email suivi envoyé automatiquement.

Gérer les produits

➕

Ajouter un nouveau produit

Via l'interface admin — pas besoin de toucher au code

1
Va sur jumuatime.com/admin-ressources.html (connectée en tant qu'admin)
2
Clique sur "+ Nouveau produit" (bouton rose en haut)
3
Remplis : titre, slug (URL automatique ou personnalisé), catégorie, type de produit, prix en euros (ex: 4.9 pour 4,90 €)
4
Upload l'image principale. Pour les numériques : upload aussi le PDF.
5
Coche "Produit actif" et "Visible en boutique" selon ton besoin
6
Clique Enregistrer — le produit apparaît immédiatement en boutique
Prix : Saisi en euros (3.9, pas 390). Le site fait la conversion en centimes automatiquement pour Stripe.
🙈

Masquer un produit temporairement

Sans le supprimer

1
Admin ressources → trouve le produit → clique l'icône œil (👁) à droite
2
Le statut passe à "Inactif" — le produit disparaît de la boutique immédiatement. Reclique pour réactiver.
Différence actif / visible boutique : "Actif" = commandable. "Visible boutique" = apparaît dans les listes. Un produit peut être actif mais caché (ex : mugs bundle-only). Les deux cases se cochent dans le formulaire produit.
✏️

Modifier le prix d'un produit

1
Admin ressources → clique le crayon ✏️ sur le produit
2
Modifie le champ Prix (en euros, ex: 12.9)
3
Enregistrer → le nouveau prix s'applique aux nouveaux ajouts au panier (les paniers existants gardent l'ancien prix)
🗑️

Supprimer définitivement un produit

1
Admin ressources → bouton corbeille rouge 🗑 sur le produit
2
Confirme dans la boîte de dialogue — la suppression est irréversible
Attention : Si des clientes ont acheté ce produit et ont des commandes actives, la suppression ne les efface pas mais peut casser les liens. Préférer "désactiver" plutôt que supprimer.

Gérer les commandes

📦

Marquer une commande comme expédiée

Envoie automatiquement l'email de suivi à la cliente

1
Admin commandes → onglet Physiques → clique sur la commande
2
Dans le panel latéral : colle le numéro de suivi La Poste dans le champ dédié
3
Change le statut en "expedie"
4
Clique Sauvegarder → l'email de suivi part automatiquement avec le lien La Poste
✍️

Créer une commande manuellement

Pour les commandes hors site (message DM, etc.)

1
Admin commandes → bouton "+ Nouvelle commande"
2
Remplis : email cliente, nom, produit, montant, adresse de livraison
3
Statut initial : en_preparation (tu l'as déjà reçue/payée hors site)
4
Enregistrer → la commande apparaît dans ta liste. Passe-la en "expedie" quand tu l'envoies.

Modifier les textes du site

Méthode universelle dans VS Code : Ouvre le fichier → Ctrl+F → tape le texte exact que tu vois sur le site → trouve-le dans le code → modifie. Enregistre (Ctrl+S) → git push pour mettre en ligne.
🔍

Trouver et modifier un texte dans le HTML

1
Dans VS Code : Ctrl+Shift+F pour chercher dans tous les fichiers à la fois
2
Tape le texte exact que tu vois sur le site (3–4 mots suffisent)
3
Clique sur le résultat → VS Code ouvre le fichier à la bonne ligne
4
Modifie entre les balises HTML (entre <p> et </p>, ou <h2> et </h2>, etc.)
5
Ctrl+S → terminal → git add -A && git commit -m "maj texte" && git push

Footer et navigation

Règle importante : Le footer existe dans chaque fichier HTML séparément — il n'y a pas de composant partagé. Si tu modifies le footer dans index.html, tu dois faire la même modification dans chaque autre page manuellement.

Modifier un lien dans le footer

1
Dans VS Code, Ctrl+Shift+F → cherche le texte du lien (ex: "Tilawa Tour") dans le fichier concerné
2
Trouve la balise <a href="...">Tilawa Tour</a>
3
Modifie l'attribut href pour changer l'URL, ou le texte entre les balises

Modifier la FAQ

La FAQ utilise des balises <details> HTML natives — pas de JavaScript. Chaque question est une balise <details> avec un <summary>.

Ajouter une question

Dans faq.html, dans la bonne section <div class="faq-section">, ajoute :

<details class="faq-item"> <summary> Ta nouvelle question ? <span class="ms chevron">expand_more</span> </summary> <div class="faq-body"> <p>La réponse à ta question ici.</p> </div> </details>

Modifier une réponse existante

Ctrl+F → cherche le texte de la question → trouve le <div class="faq-body"> juste en dessous → modifie le texte.

Zones dangereuses — ne pas toucher seule

🚨 JAMAIS :
  • Modifier Stripe en mode TEST — on est en LIVE (vrais paiements). Ne pas changer le mode.
  • Supprimer une table Supabase (resources, commandes_physiques, purchases...) — irréversible.
  • Modifier supabase-client.js — casse toutes les pages du site.
  • Modifier les Edge Functions Supabase (stripe-checkout, stripe-webhook, swift-function) — nécessite Claude.
  • Changer un slug déjà publié — casse les liens Google et les URL partagées.
  • Utiliser une balise <form> dans le HTML — tout doit passer par des event handlers JS.
⚠️ Prudence :
  • Modifier bundle_items en JSON brut dans Supabase — utiliser l'interface admin si possible.
  • Modifier gelato_product_id — vérifier l'ID exact dans ton catalogue Gelato avant.
  • Supprimer un produit avec commandes actives — préférer "désactiver".

Dépannage rapide

Un produit n'apparaît pas en boutique

1
Vérifie dans admin-ressources : le produit est-il Actif (œil non barré) ? Visible boutique cochée ?
2
Vérifie dans Supabase table resources : is_active = true ET visible_boutique = true
3
Vide le cache du navigateur (Ctrl+Shift+R) — Cloudflare cache parfois les pages

Une page affiche une erreur ou est blanche

1
Appuie sur F12 dans Chrome → onglet Console → lis l'erreur en rouge
2
L'erreur mentionne un fichier et une ligne — note-les
3
Si l'erreur dit "is not defined" : une fonction JS est manquante ou mal orthographiée
4
Partage le message d'erreur exact avec Claude au prochain message

Le site n'est pas mis à jour après un git push

1
Va sur dash.cloudflare.com → Pages → jumuatime → Deployments
2
Vérifie que le dernier déploiement est en Success (vert). S'il est en échec (rouge) : lis l'erreur de build.
3
Si Success mais le site n'est pas à jour : Ctrl+Shift+R pour vider le cache navigateur

L'email de suivi n'est pas parti

1
Vérifie dans admin-commandes que le statut est bien passé à expedie (et non juste sauvegardé)
2
Vérifie sur resend.com/dashboard que l'email a bien été envoyé (onglet Emails)
3
Si erreur dans Resend : note le message et partage-le avec Claude

Commande arrivée mais sans email de confirmation cliente

Va dans Resend → Emails et cherche par l'email de la cliente. S'il n'y est pas, le webhook Stripe n'a pas fonctionné. Crée une commande manuelle dans admin-commandes pour garder la trace, et envoie un email personnalisé à la cliente.
